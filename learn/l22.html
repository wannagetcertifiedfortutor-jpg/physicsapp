Conservative vs non-conservative forces

Test path independence; recognize which forces admit a potential energy.

Sample problem · AP Multiple Choice

An object is moved along a closed path that starts and ends at the same point. For which of the following forces is the total work done on the object around the path necessarily zero?

  1. The air resistance force
  2. The force exerted by a person pushing the object along the path
  3. The kinetic friction force exerted by the floor
  4. The gravitational force exerted by earth
Sample problem · AP Multiple Choice

A particle is carried counter-clockwise around the square with corners (0,0), (1,0), (1,1), (0,1) (meters) under the force F=2(y^+x^​) (newtons, with x,y in meters). Evaluate the work W=∮F⋅dr around the loop and interpret it.

  1. W=0, which proves the force is conservative because the loop integral vanished for this one path.
  2. W=2 J; the top and right sides contribute but the bottom and left do not.
  3. W=2⋅2⋅12=4 J; the force is not conservative.
  4. W=0 around this loop, consistent with the force being conservative (indeed F=∇(αxy)).
